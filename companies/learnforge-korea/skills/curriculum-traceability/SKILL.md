# Curriculum Traceability

## Required inputs

- Approved or approval-pending scope statement
- Source documents supplied for the project, with title/version/location
- Stable IDs for intended outputs

## Procedure

1. Record each source without paraphrasing it as an official requirement unless the source supports that wording.
2. Assign stable IDs to scope statements, learning intentions, and observable evidence statements.
3. Map each item or activity to at least one evidence statement; map every evidence statement to its source and scope status.
4. Mark interpretations, assumptions, exclusions, conflicts, and missing sources separately.
5. Check both directions: source to output coverage and output to source justification.
6. After a change, list affected IDs and recheck only after all dependent artifacts are updated.

## Durable output

A trace table with source/version, scope ID, learning-intention ID, evidence ID, output ID, status, rationale, and reviewer. Include uncovered requirements, unjustified outputs, and decisions awaiting human scope/curriculum approval.

## Done checks

- No output lacks an evidence link.
- No claimed requirement lacks an identified source.
- Scope gaps and conflicts have an owner and action.
- Final scope/curriculum approval remains explicitly human-owned.
