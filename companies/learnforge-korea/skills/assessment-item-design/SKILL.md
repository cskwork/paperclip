# Assessment Item Design

## Required inputs

- Approved or approval-pending scope and trace table
- Evidence statements and misconception notes
- Target item count, formats, and delivery constraints

## Procedure

1. Build a blueprint across evidence ID, content focus, intended cognitive demand, item format, and difficulty intent before drafting.
2. Write each item from scratch; do not imitate or adapt proprietary assessment wording.
3. Define prompt, response mode, accepted answer, scoring rule, worked solution, feedback intent, and trace IDs.
4. Tie distractors to documented error patterns without trick wording, irrelevant reading load, or answer-position cues.
5. Independently recompute the answer and test alternative valid forms, ambiguous interpretations, and edge inputs.
6. Review blueprint balance and record every deviation rather than silently changing scope.

## Durable output

A versioned blueprint and item record for each item: item ID, trace IDs, prompt, response contract, answer, solution, scoring, distractor rationale, accessibility notes, and review status.

## Done checks

- Item count and blueprint coverage match the assigned scope.
- Every item is original and bidirectionally traceable.
- Answers, scoring, and alternative valid responses are explicit.
- Ambiguous, misleading, or out-of-scope items are removed or blocked.
