# 중학교 수학 평가 팩

## Scope

첫 출시 후보는 중학교 1학년 정수와 유리수 평가 팩이다. 교육과정 추적표, 오개념 근거, 평가 청사진과 자체 작성 문항 24개, 정답·풀이·채점 기준, 접근 가능한 상호작용 패키지, 독립 QA, 권리·개인정보·접근성 게이트, 출시·학습분석 계획을 하나의 버전으로 묶는다.

## Workflow

`01-product-brief` → `02-curriculum-map` → `03-misconception-research` → `04-assessment-blueprint-items` → `05-interactive-package` → `06-independent-editorial-qa` → `07-rights-privacy-accessibility-review` → `08-release-analytics-plan`

수정이 발생하면 영향받은 추적 ID를 따라 앞 단계 담당자에게 되돌리고, 독립 QA와 게이트를 다시 수행한다. 프로젝트 파일은 실행 목표를 자동 생성하지 않으므로 가져오기 후 사람이 런타임 목표를 만든다. 모든 외부 출시는 인간 승인 전까지 차단된다.
