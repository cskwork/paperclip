## Input

교육과정 추적표, 오개념 근거 메모, 승인된 문항 수·형식·전달 제약.

## Output

내용·인지 요구·형식·난이도 의도가 균형을 이룬 청사진과 자체 작성 문항 24개. 각 문항에는 ID, 추적 ID, 정답, 풀이, 채점 기준, 대안 정답, 오답 근거, 피드백 의도를 포함한다.

## Dependency

`02-curriculum-map`과 `03-misconception-research` 완료.

## Acceptance

- 정확히 24개 문항이 청사진과 양방향으로 추적된다.
- 모든 계산과 풀이가 독립 재계산 가능하다.
- 모호한 표현, 답 단서, 불필요한 읽기 부담, 범위 밖 요구가 없다.
- 외부 문항·출판사 자산을 복제하거나 변형하지 않았다.

## Human gate

청사진이 승인된 범위를 바꾸는 경우 사람이 범위·교육과정 적합성을 다시 승인해야 한다.
